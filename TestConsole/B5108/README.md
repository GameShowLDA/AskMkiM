# Б5-108: исследование LAN/SCPI

Работа ведётся только в TestConsole. Production-драйвер не изменяется.

Источники: руководство производителя ВЛЕТ.418111.004 РП (2022),
https://www.electronpribor.ru/files/products/b5_300vt-prog.pdf;
РЭ: https://www.electronpribor.ru/files/products/b5_300vt.pdf.
Ниже — документированные команды, а не утверждение о проверке всех команд на приборе.
Фактические ответы сохраняются отдельно в `probe-results.txt`.

## Запуск

Из корня репозитория:

```powershell
dotnet run --project TestConsole --no-build -- b5-108 192.168.1.17 80
dotnet run --project TestConsole --no-build -- b5-108 192.168.1.17 80 --interactive
dotnet run --project TestConsole --no-build -- b5-108 192.168.1.17 80 --characterize
dotnet run --project TestConsole --no-build -- b5-108 192.168.1.17 80 --characterize --output-test
```

Пункт 24 главного меню открывает подменю Б5-108 для 192.168.1.17:80:
1. Проверка команд чтения.
2. Проверка параметров без включения выхода.
3. Проверка параметров и включения на минимальных уставках.
4. Ручной ввод SCPI.
5. Установка U/I с программным шагом 0,1 В / 0,001 А, только при выключенном выходе.
0. Возврат в главное меню.

В пунктах 2–3 после исследуемой записи уставки выдерживается 1,5 с, чтобы наблюдать
изменение на дисплее; заданное и прочитанное значение выводятся в консоль.
Микроизменения могут быть меньше разрядности дисплея — их видно по обратному чтению SCPI.
В консоли также показываются минимум, максимум и найденный шаг каждого параметра.
После завершения результат остаётся на экране до Enter, затем снова показывается подменю.
CLI-флаг `--display` включает такие же паузы при `--characterize`.

`--settings` открывает установку U/I (также пункт 5 подменю).
Напряжение кратно 0,1 В, ток кратен 0,001 А; ввод тока в амперах.
Допускаются точка и запятая. Некратные и выходящие за текущий LIM значения
отклоняются без отправки. Уставка читается обратно и сравнивается с введённой.
При выходе новые уставки остаются на приборе; OUTP ON и *SAV не отправляются.
Это программный шаг данного меню; диагностический поиск разрешения SCPI и сырой
ручной ввод команд остаются отдельными режимами.
Автоматически выполняются только запросы. `SYST:ERR?` извлекает элементы очереди;
поэтому сначала выводятся старые ошибки, затем ошибки после каждого запроса.
При таймауте соединение закрывается: поздний ответ не приписывается следующему запросу.
Ручной режим разрешает ввод команд изменения параметров; команды с `?` ожидают ответ.
Пакеты из нескольких SCPI-команд для ручного режима не использовать.

## Протокол

TCP, ASCII; окончания отправки LF (также документирован CR), ответа LF.
Заводской адрес 192.168.1.25, порт 80; адрес пользователя предположительно 192.168.1.17.
Десятичный разделитель — точка. Ни HTTP, ни порт 5025 автоматически не предполагаются.
В таблицах приведены короткие SCPI-формы, `<value>` заменяется числом после пробела.

## Полный каталог из РП

| Команда | Назначение |
| --- | --- |
| `*IDN?` | Производитель, модель, серийный номер, версия ПО |
| `*SAV` | Сохранение конфигурации в энергонезависимой памяти |
| `*RST` | Перезапуск, аналог выключения/включения питания |
| `[SOUR:]VOLT[:LEV] <value>` / `?` | Уставка напряжения, В |
| `[SOUR:]VOLT:LIM <value>` / `?` | Верхняя граница напряжения |
| `[SOUR:]CURR[:LEV] <value>` / `?` | Уставка ограничения тока, А |
| `[SOUR:]CURR:LIM <value>` / `?` | Верхняя граница тока |
| `MEAS:VOLT?` | Измеренное напряжение, В |
| `MEAS:CURR?` | Измеренный ток, А |
| `STAT:OPER:COND?` | Состояние: бит 0 — выход, 1 — CC, 2 — дистанционное управление |
| `OUTP[:STAT] <0\|1\|OFF\|ON>` / `?` | Выход выключен/включён |
| `OUTP:PON <0\|1\|2\|OFF\|ON\|AUTO>` / `?` | Состояние выхода после включения питания |
| `CAL:PASS <code>` | Разрешение калибровки по индивидуальному коду |
| `CAL:STAT?` | Разрешена ли калибровка |
| `CAL:SAV` | Сохранение калибровки |
| `CAL:STOP` | Выход из калибровки |
| `CAL:DEF` | Сброс калибровки |
| `CAL:VOLT[:LEV] <value>` | Установка калибровочного напряжения |
| `CAL:VOLT:MEAS <value>` | Внесение показания внешнего эталона напряжения |
| `CAL:CURR[:LEV] <value>` | Установка калибровочного тока |
| `CAL:CURR:MEAS <value>` | Внесение показания внешнего эталона тока |
| `SYST:ERR?` | Чтение очереди ошибок |
| `SYST:VERS?` | Версия SCPI (в РП: 1999.0) |
| `SYST:DEF` | Сброс системных настроек |
| `SYST:COMM:UPD` | Применение параметров интерфейсов |
| `SYST:COMM:GPIB:ADDR <value>` / `?` | Адрес GPIB |
| `SYST:COMM:LAN:IPAD <address>` / `?` | Статический IP |
| `SYST:COMM:LAN:PORT <value>` / `?` | TCP-порт |
| `SYST:COMM:LAN:SMAS <mask>` / `?` | Маска подсети |
| `SYST:COMM:LAN:GAT <address>` / `?` | Шлюз |
| `SYST:COMM:LAN:MAC?` | MAC-адрес |

Запись MAC в тексте РП дана как `SYSTem:COMMunicate:MAC <string>`,
а чтение — с узлом LAN; это расхождение требует проверки, запись не запускается.
В примерах UPDate/GPIB встречается `COMMunicat` вместо `COMMunicate`;
в описаниях VOLT:LIM/CURR перепутаны физические величины.
Точность текстового представления до микроединиц не равна метрологической точности прибора.
В РП не заявлены `*CLS`, `*OPC?`, `SYST:REM`, `SYST:LOC`, команды мощности или выбора CV/CC.
Наличие ограничения мощности в экранном меню не доказывает наличие SCPI-команды.

## Ошибки из РП

0 — нет ошибок; 1 — синтаксис; 2 — данные команды; 3 — параметр вне диапазона;
101 — калибровка запрещена; 102 — неверный пароль; 107 — калибровочное значение вне диапазона;
120 — калибровка напряжения в CC; 121 — калибровка тока в CV; 255 — переполнение очереди.

## Граница проверки

Автоопрос проверяет короткие формы запросов и очередь ошибок на текущей прошивке.
Он не подтверждает выполнение setters, сохранение, сброс, изменение сети и калибровку.
Для проверки установок/выхода требуется отдельно определить нагрузку и допустимые U/I.
Сетевые изменения могут разорвать соединение; калибровочные команды меняют метрологические данные.

## Определение диапазона и шага

`B5108Probe.Characterization.cs`: `CharacterizeAsync` сохраняет исходные уставки;
`FindRangeAsync` записывает ноль и текущий LIM, проверяет ошибку и читает результат;
`FindStepAsync` увеличивает пробную добавку от 0.0000001 десятикратно до изменения обратного чтения.
Шаг проверяется у минимума, в середине и около 99% диапазона. Это наблюдаемое
разрешение SCPI-уставки по выбранным пробам, не метрологический шаг ЦАП и не доказательство
единого шага во всех точках. Максимум относится к текущему LIM, который не изменяется.
Перед каждой записью проверяется выключенное состояние выхода.
В `finally` восстанавливаются исходные U/I, сохранение в EEPROM не выполняется.
При потере связи восстановление может оказаться невозможным; ошибка выводится в консоль.

Проверено на приборе 240026 / 1.05 2026-10-29:

| Параметр | Минимум | Максимум при текущем LIM | Наблюдаемый шаг SCPI |
| --- | --- | --- | --- |
| Напряжение | 0 В | 150 В | 0.000001 В |
| Ток | 0 А | 5 А | 0.000001 А |

Добавка 0.0000001 при обратном чтении не сохраняется, 0.000001 сохраняется
во всех трёх исследованных точках каждого параметра.
Лог: `characterization-resolution.txt`.

`--output-test` дополнительно включает выход на минимальных положительных найденных уставках
(не более 0.01 В / 0.01 А), читает измерения и выключает выход в `finally`.
Первый реальный тест при 0.000001 В / 0.000001 А: OUTP=1,
MEAS:VOLT=0.002308 В, MEAS:CURR=0 А; после OUTP OFF подтверждено OUTP=0.
Лог: `characterization-results.txt`. Это проверка управления выходом без нагрузки,
а не подтверждение точности воспроизведения микровольта или микроампера.
Исходные 0.01 В / 0.01 А восстановлены и прочитаны обратно.
