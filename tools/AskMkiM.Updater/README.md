# Автономное обновление AskMkiM

Инструмент создаёт один автономный EXE с новой версией AskMkiM и устанавливает его
на компьютере без интернета и прав администратора.

## Подготовка конструктора

Из корня репозитория выполните:

```powershell
./tools/AskMkiM.Updater/publish.ps1
```

В `artifacts/AskMkiM.Updater.Authoring` будут созданы два файла:

- `AskMkiM.UpdateBuilder.exe` — окно формирования обновления;
- `AskMkiM.Updater.Stub.exe` — готовая заготовка автономного установщика.

Оба файла должны находиться рядом. Пользователь запускает только
`AskMkiM.UpdateBuilder.exe`.

## Формирование релиза

1. Опубликуйте AskMkiM обычным способом.
2. Запустите `AskMkiM.UpdateBuilder.exe`.
3. Выберите каталог опубликованной сборки с `AskMkiM.exe` и `build-manifest.json`.
4. Укажите имя выходного EXE и нажмите «Создать обновление».
5. Перенесите полученный файл на закрытый компьютер.

Конструктор не включает изменяемые данные установки: SQLite-базу, настройки,
роли, архивы, историю, резервные копии, логи и аварийные отчёты.

## Установка

Автономный EXE сначала проверяет сохранённый путь к AskMkiM, затем стандартные
пути `C:\AskMkiM\Bin\AskMkiM.exe` и `D:\AskMkiM\Bin\AskMkiM.exe`. Если приложение
не найдено, пользователь выбирает `AskMkiM.exe` вручную.

Перед заменой создаётся каталог `UpdateBackups` со следующими данными:

- заменяемые программные файлы;
- `Resources/app.db`;
- `Resources/role-auth.json`;
- содержимое `Settings`;
- манифест выполненного обновления.

При ошибке замены программные файлы автоматически восстанавливаются. Обновление
не выполняется при запущенном AskMkiM, отсутствии прав записи, повреждении пакета,
совпадении сборок или попытке установить более старую версию.
