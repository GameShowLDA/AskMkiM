Меню «Тесты»

Подменю «Испытания → Тесты» открывает проверки сопротивления изоляции, прочности изоляции, коммутации МКР и сопротивления контактов коммутатора. Каждый пункт открывает рабочую вкладку с параметрами и протоколом. Проверка начинается только после нажатия «Запустить».

Доступные проверки

Пункт менюНазначениеЧто выбрать
Тест СИ Измерение сопротивления изоляции в МОм и сравнение с заданным минимумом. Метод узла или групповой метод.
Тест ПИ на постоянном токе Испытание прочности изоляции постоянным напряжением (DCW), измерение тока утечки в мА. Метод узла или групповой метод.
Тест ПИ на переменном токе Испытание прочности изоляции переменным напряжением (ACW) с частотой 50 Гц, измерение тока утечки в мА. Метод узла или групповой метод.
Перекрёстный тест (МКР) Проверка коммутации выбранного МКР с помощью другого, проверяющего модуля. Проверяемый и проверяющий модули, диапазон и остальные параметры теста.
Сопротивление коммутатора Контроль сопротивления контактов коммутатора с помощью мультиметра. Диапазон точек, электрический параметр и пару шин.

Как выбрать тест

  • Для проверки минимального сопротивления изоляции используйте СИ. Условие успешного результата — сопротивление не ниже заданного минимума.
  • Для испытания изоляции напряжением с контролем тока утечки используйте ПИ. Выберите DCW или ACW в соответствии с требуемым видом испытания. Ток должен быть строго меньше заданного предела.
  • Для проверки коммутации с участием двух МКР используйте перекрёстный тест.
  • Для контроля сопротивления контактов используйте «Сопротивление коммутатора».

В СИ и ПИ метод узла последовательно проверяет каждую точку относительно остальных точек диапазона. Групповой метод проверяет разбиения точек на две группы и показывает результат по разрядам группировки.

Порядок работы

  1. Откройте «Испытания → Тесты» и выберите проверку. Для СИ и ПИ дополнительно выберите метод.
  2. Заполните параметры в открывшейся вкладке. Состав полей зависит от выбранного теста.
  3. Нажмите «Запустить». Приложение проверит ввод и подготовит оборудование.
  4. Следите за ходом проверки, измерениями и сообщениями в протоколе. При ошибке ориентируйтесь на её описание и запрос приложения.

Для запуска тестов не требуется открывать или транслировать программу контроля. Оборудование выбирается из конфигурации приложения. Эти проверки не заменяют метрологические режимы сравнения с эталоном.

Меню доступно администраторам и регулировщикам. Для роли разработчика оно скрыто.
