Тест СИ

Раздел «Тест СИ» содержит проверки сопротивления изоляции между точками заданного диапазона. Пробойная установка подаёт испытательное напряжение и измеряет сопротивление в мегаомах (МОм). Результат сравнивается с минимальным сопротивлением, указанным пользователем.

Откройте «Испытания → Тесты → Тест СИ» и выберите способ проверки.

Выбор метода

Пункт менюКак выполняется проверкаРезультат
Метод узла Каждая точка последовательно проверяется относительно остальных точек диапазона, объединённых на противоположной шине. Измеренное сопротивление и оценка для каждой проверяемой точки.
Групповой метод Точки распределяются между шинами А и В по разрядам двоичного представления их номеров. Для каждого разбиения измеряется сопротивление между группами. Измеренное сопротивление и оценка для каждого разряда группировки.

Метод узла позволяет связать неудовлетворительный результат с конкретной проверяемой точкой относительно остальных. Групповой метод оценивает сформированные группы; сообщение по разряду само по себе не указывает отдельную неисправную пару.

Что нужно задать

  • Начальную и конечную точки — границы диапазона включительно. Адрес a.b.c задаёт шасси, модуль коммутации и точку.
  • Электрический параметр — минимально допустимое сопротивление в МОм.
  • Время выполнения — длительность одного измерения в секундах.
  • Напряжение — испытательное напряжение в вольтах.
  • Для группового метода дополнительно выберите шину А или В. В методе узла СИ выбор шины пользователем не требуется.

Порядок работы

  1. Выберите метод в меню. Откроется отдельная рабочая вкладка с параметрами и протоколом.
  2. Введите диапазон точек, минимальное сопротивление, время и напряжение. Для группового метода выберите шину.
  3. Нажмите «Запустить». Приложение проверит параметры и подключение оборудования.
  4. Следите за измеренными значениями и сообщениями в протоколе. При ошибке ориентируйтесь на указанную точку или разряд группировки и запрос приложения.

Оценка результата

Проверка успешна, если измеренное сопротивление не ниже заданного минимума: равенство порогу допускается. При меньшем сопротивлении выводится сообщение об ошибке.

Это проверка по минимальному сопротивлению, а не метрологическое сравнение с эталоном. Заданное время относится к одному измерению; общая длительность зависит от числа проверок и повторов. Открытие вкладки не запускает тест и не требует трансляции программы контроля.

Меню тестов доступно администраторам и регулировщикам; для роли разработчика оно скрыто. Оборудование выбирается из конфигурации приложения, допустимые параметры проверяются перед выполнением.
