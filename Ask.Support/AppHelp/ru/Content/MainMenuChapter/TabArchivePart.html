Меню «Архив»

Меню «Архив» объединяет работу с архивами программ контроля: открытие окна архивов, создание нового архива, экспорт на диск и импорт готового архива. Рабочий формат архивов — .apkw.

Архив хранит набор файлов программ контроля. В окне архивов можно выбрать нужный архив, просмотреть его состав и перейти к работе с отдельной программой.

Команды меню

КомандаДействие
Открыть архив Открывает вкладку «Архив» со списком доступных архивов. Нужный архив выбирается уже в этой вкладке.
Создать архив Открывает окно создания архива. Если вкладка архивов не активна, сначала открывает её. Для создания нужны права на изменение архивов.
Экспортировать архивы Копирует все архивы из каталога приложения в выбранную папку, сохраняя структуру вложенных папок.
Импортировать архив Добавляет выбранный файл .apkw в каталог архивов приложения.

С чего начать

  • Чтобы найти программу в уже имеющихся архивах, выберите «Открыть архив», затем нужный архив и файл внутри него.
  • Чтобы добавить готовый архив с другого компьютера или носителя, выберите «Импортировать архив».
  • Чтобы перенести весь набор архивов на другой носитель, выберите «Экспортировать архивы».
  • Чтобы подготовить отдельный архив для программ контроля, выберите «Создать архив».

Обмен архивами

При экспорте в выбранной папке создаётся каталог «Скачанные архивы». Если такой каталог уже есть, создаётся новый с отметкой времени. Архивы в приложении при этом остаются на месте.

Импорт копирует архив в каталог приложения и сохраняет исходный файл. Если архив с таким именем уже есть, приложение сообщает об этом и не заменяет его.

Для преобразования архивов старого формата .apk используйте «Файл → Конвертация».

Доступность команд

Команды меню не требуют заранее открытой вкладки архивов. Создание и изменение содержимого доступны пользователям с правами на редактирование архивов; при недостаточных правах приложение сообщает об ограничении.

Во время работы с аппаратурой действия меню блокируются с сообщением. Завершите выполнение и повторите нужную команду.

Другие функции окна архивов

Сохранение одного архива на диск, печать его каталога и другие действия с выбранным архивом описаны в разделе «Операции с архивами».

Просмотр программ, копирование файлов, преобразование в .pkw и запуск в исполнителе описаны в разделе «Операции с файлами архива». Доступные действия зависят от выбранного элемента и прав пользователя.

Открытие окна архивов или выбор файла не запускает проверку изделия. Запуск программы в исполнителе вызывается отдельным действием.
