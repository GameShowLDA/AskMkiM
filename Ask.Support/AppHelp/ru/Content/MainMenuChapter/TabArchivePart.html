Меню «Архив»

Меню предназначено для открытия окна архивов и обмена архивами программ контроля с внешними папками. Архивы хранятся в формате *.apkw.

Команды меню

  • Открыть архив — открывает рабочее окно архивов.
  • Создать архив — создаёт новый архив программ контроля.
  • Экспортировать архивы — сохраняет все архивы в выбранную папку.
  • Импортировать архив — добавляет в программу архив из файла *.apkw.

Команда «Открыть архив» доступна постоянно. Остальные команды появляются, когда рабочее окно архивов активно.

Другие функции окна архивов

В рабочем окне можно открыть выбранный архив, сохранить один архив на диск, преобразовать его для старой версии программы, распечатать каталог, добавить или вставить файл и удалить архив.

Для файлов архива доступны просмотр содержимого, открытие в текстовом редакторе, копирование, вырезание, вставка, преобразование в *.pkw, запуск в исполнителе и удаление. Эти действия описаны в отдельных темах раздела.
