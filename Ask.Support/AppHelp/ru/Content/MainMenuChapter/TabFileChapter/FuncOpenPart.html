Открыть файл

Открывает программы контроля, архивы, протоколы и текстовые файлы.

В меню
Файл → Открыть
Клавиши
Ctrl + O

Как открыть файл

  1. Выберите Файл → Открыть или нажмите Ctrl + O.
  2. В окне «Выберите файл» найдите нужный файл. При необходимости выберите фильтр по типу файла.
  3. Дважды щёлкните файл или выделите его и нажмите Открыть.

Можно выбрать несколько файлов и открыть их одновременно.

Во время работы с аппаратурой открытие файлов недоступно. Сначала завершите выполнение.
