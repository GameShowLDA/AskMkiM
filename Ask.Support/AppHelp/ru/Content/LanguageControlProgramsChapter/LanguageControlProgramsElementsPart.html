2. Элементы языка АСК

Текст состоит из номеров команд, мнемоник, параметров, адресов и разделителей. Для мнемоник используйте русские буквы; регистр не влияет на распознавание команды. Похожая латинская буква не заменяет русскую автоматически.

Пробелы и переносы

Номер и мнемонику разделяют пробелом. Параметры и список точек можно переносить на следующие строки. Строка с номером и мнемоникой распознаётся как начало новой команды; не оформляйте продолжение в таком виде.

100 ПР Ом<10
    *1,2,3*4,5*

Комментарии

Поддерживаются однострочные комментарии //, блоки /* … */ и { … }. Их содержимое не является параметрами команды. Для обращения к оператору используйте ЦУ.

100 ПР Ом<10 *1,2*3,4* // проверка монтажа
/* Пояснение к программе */
{ Дополнительное пояснение }

Числа и единицы

Для параметров используйте обычную десятичную запись, например 0.5, и явно указывайте единицу измерения. Набор допустимых единиц зависит от параметра. Научная запись с e не является универсальным форматом параметров.

Обозначения точек

Адресами изделия могут служить обозначения 1, Х1/5, Х1:5. Обозначение должно присутствовать в РМ либо быть объявленным там синонимом. Для обозначений точек при поиске по РМ не учитывается регистр и нормализуются поддерживаемые похожие русские и латинские буквы. Это правило не распространяется на мнемоники команд. Ведущие нули в адресах не следует произвольно добавлять или удалять.
