5.3.4 Команда СК (Сброс Коммутатора)

СК отключает точки релейных модулей от выбранных шин. Без списка шин сбрасываются точки со всех шин. Измерительные приборы эта команда не сбрасывает. При двухшинной структуре ВШ (2Ш) команда СК запрещена транслятором; для общего сброса используйте ОС.

Синтаксис и примеры

230 СК *А1,В2*
240 СК

Первая команда сбрасывает точки только с А1 и В2, вторая — со всех шин. Операция выполняется для модулей текущего запуска.

Для общего сброса оборудования используйте ОС.
