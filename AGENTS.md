# Repository Agent Instructions

## Пользовательская справка

1. При обновлении любого раздела справки проверяй актуальный production-код:
   пункты UI, обработчики команд, ограничения доступа и фактическую реализацию.
   Существующая справка не является достаточным подтверждением функциональности.
2. Не описывай в пользовательской справке функции и разделы, доступные только root,
   и не раскрывай сведения о скрытом доступе к ним. Правило действует для всех разделов.
3. Описывай доступность остальных функций по фактическим условиям в коде.
4. Если для описываемого пункта ещё нет подробной статьи, создавай пустую страницу
   с заголовком и общими стилями, добавляй её в дерево справки и поставку приложения,
   а название пункта делай ссылкой. Содержимое будет заполняться при разборе раздела.
5. После полной проверки и переработки статьи помечай её узел в `AppHelp/ru/index.html`
   атрибутом `data-reviewed="true"`. Без этого атрибута справа отображается жёлтая
   отметка «!». Открытие страницы не меняет редакционный статус; частично обновлённые
   статьи сохраняют отметку. Статус папки относится к её собственной статье, а не ко всем потомкам.

## Architecture Map

1. Перед широким исследованием репозитория сначала прочитай
   [`docs/ARCHITECTURE_MAP.md`](docs/ARCHITECTURE_MAP.md).
2. Используй карту, чтобы определить затрагиваемые проекты, типы, точки входа,
   DI-регистрации и runtime call chains.
3. Не сканируй весь репозиторий заново, если карта содержит достаточно сведений
   для навигации по текущей задаче.
4. Для изменяемого участка обязательно проверь актуальный production-код.
5. При конфликте карты и исходного кода доверяй исходному коду и исправь карту.
6. После архитектурно значимого изменения обнови только затронутые разделы карты,
   сохраняя стабильные заголовки, anchors и внутренние ссылки.
7. Обновление карты входит в Definition of Done для изменений проектов,
   зависимостей, DI, интерфейсов, реализаций, adapters, drivers, factories,
   call chains, Real/Idle, error/event flows, background operations, БД,
   конфигурации и основных UI-потоков.
